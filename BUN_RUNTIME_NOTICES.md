# Bun runtime notices

`ocu`, `ocu-host` and `ocu-engine`, in `Open Computer Use.app/Contents/MacOS`, are standalone executables made with `bun build --compile` (Bun 1.3.10, darwin-arm64). Each contains the Bun runtime, and with it the components below. Open Computer Use's own code and the npm packages it bundles are in `THIRD_PARTY_NOTICES.md`.

Pinned versions come from Bun's build files at tag `bun-v1.3.10`; the embedded Node.js polyfill packages from rebuilding Bun's `src/node-fallbacks` with its lockfile. WebKit's third-party code is covered by its top-level license files below. ICU and SQLite are not included: on macOS Bun uses the system's copies.

## Source code and relinking

Some components are under licenses that require their source code to be available:

- JavaScriptCore, WTF and the WebCore files Bun uses, from Bun's WebKit fork at commit `4a6a32c32c11ffb9f5a94c310b10f50130bfe6de` (https://github.com/oven-sh/webkit/tree/4a6a32c32c11ffb9f5a94c310b10f50130bfe6de): GNU LGPL 2.0 and 2.1.
- TinyCC, from Bun's fork at commit `12882eee073cfe5c7621bcfadf679e1372d4537b` (https://github.com/oven-sh/tinycc/tree/12882eee073cfe5c7621bcfadf679e1372d4537b): GNU LGPL 2.1.
- The Rust crates cssparser 0.36.0, cssparser-macros 0.6.1, selectors 0.33.0 and dtoa-short 0.3.5, used by lol-html: Mozilla Public License 2.0. Their source is on crates.io (https://crates.io) at those versions.

Bun's own source at the shipped version: https://github.com/oven-sh/bun/tree/bun-v1.3.10. Open Computer Use's source: https://github.com/andrewslabmd/opencomputeruse.

**Relinking with a modified library.** The LGPL lets you run Open Computer Use with your own version of these libraries:

1. Build Bun 1.3.10 from its source with your modified WebKit or TinyCC (Bun's `LICENSE.md` and build documentation describe how: set its WebKit to your copy, then build).
2. Build Open Computer Use from its source with your Bun: `OCU_BUN=/path/to/your/bun pnpm build`. The three executables then embed your runtime.

Bun statically links JavaScriptCore (and WebKit) which is LGPL-2 licensed. WebCore files from WebKit are also licensed under LGPL2. Per LGPL2:

> (1) If you statically link against an LGPL’d library, you must also provide your application in an object (not necessarily source) format, so that a user has the opportunity to modify the library and relink the application.

You can find the patched version of WebKit used by Bun here: <https://github.com/oven-sh/webkit>. If you would like to relink Bun with changes:
