# Changelog

## 0.1.3 — 2026-10-29

[Finder folders and aliases open reliably](https://github.com/andrewslabmd/opencomputeruse/releases/tag/v0.1.3)
with repeated double-clicks and context menus. Escape and menu cancellation
close menus in the background. Unsupported file drags report their limitation;
use copy and paste to transfer files. MCP connections report the installed
version. Added a Claude Code plugin and manual setup guides for VS Code,
Gemini CLI and Claude Desktop.

## 0.1.2 — 2026-10-21

[After allowing Screen Recording](https://github.com/andrewslabmd/opencomputeruse/releases/tag/v0.1.2),
Quit & Reopen brings the app back; before, it stayed closed.

## 0.1.1 — 2026-10-21

[Settings → Overview](https://github.com/andrewslabmd/opencomputeruse/releases/tag/v0.1.1)
says "No agent is controlling your computer" when no agent is using an app.
Tested end to end from the public download: install, permissions, an agent
task, then the update from 0.1.0 with permissions kept.

## 0.1.0 — 2026-10-19

First signed release, on
[GitHub Releases](https://github.com/andrewslabmd/opencomputeruse/releases/tag/v0.1.0):
a notarized disk image with Sparkle updates you approve. Background
observation and actions in native Mac apps for MCP agents, several agents at
once with their own cursors, Stop from the menu bar, and agent setup for
Claude Code, Codex, Cursor and OpenCode. macOS 15 or later on Apple silicon.
