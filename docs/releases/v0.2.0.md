- **Watch your agents live.** Open the menu-bar panel and each agent's row shows the app it's working in, live, with its own cursor, even when that window is behind your others. Several agents show side by side.
- **Agents see apps through a live view.** While an agent works in an app, Open Computer Use keeps a live view of that window, so the agent's screenshots come from what's on screen right now. macOS shows its purple capture mark in that window's title bar the whole time, so you always know. To have agents take a single picture only when they need one, choose Settings → Overview → How agents see apps → Screenshots only.
- macOS may ask you to confirm Screen Recording again ("… requesting to bypass the system private window picker …"). Choose Allow to keep screenshots and the live view working.
- While an agent types, its cursor's name tag reads "Typing". It never shows what's typed.
- Other programs can show an agent's window too, through a private local connection; any that do are named in the agent's row ("Watched by …"). `ocu stream` saves a short clip of an agent's window.
