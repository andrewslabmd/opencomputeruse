# Open Computer Use 0.1.0

The first signed release. Open Computer Use lets coding agents such as Claude
Code, Codex, Cursor and OpenCode observe and operate native Mac apps in the
background, while you keep your pointer, keyboard and foreground app.

- Observe apps through Accessibility, with an optional screenshot of the app's own windows.
- Click, type, select, scroll, drag, press keys and open apps without moving your cursor.
- Several agents at once, one per app, each with its own colored cursor.
- Stop every agent from the menu bar.
- Connect agents from Settings or with `ocu setup`.
- Signed and notarized by Apple, with updates you approve.

Requires macOS 15 or later on Apple silicon.
