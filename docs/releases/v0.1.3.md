# Open Computer Use 0.1.3

- Finder folders and aliases open reliably with repeated double-clicks and
  context-menu commands. Context menus remain usable beyond the file view,
  and Escape and menu cancellation close them in the background.
- File drags that macOS cannot complete in the background now report that
  limitation instead of appearing successful. Use Finder’s copy and paste
  commands to transfer files.
- Agents now see the installed app’s version when connecting over MCP.
- Added a Claude Code plugin with setup and operating instructions, plus
  manual setup guides for VS Code, Gemini CLI and Claude Desktop.

Requires macOS 15 or later on Apple silicon.
