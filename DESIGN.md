# Design

A native menu-bar utility with a compact window. Status, Stop/Resume, permission setup, connections (with the app each agent is working in), CLI setup, and diagnostics should be directly accessible. Use platform typography, semantic colors, standard controls, and concise actionable messages.

The development UI is implemented but has not received visual acceptance. Do not display internal backend names in ordinary product controls. Third-party notices remain available in distribution resources.

Agent cursors: each agent's pointer is the Phosphor navigation arrow from the app icon, tinted with the agent's color (blue, purple, orange, green, pink, teal by order), with a white outline, a small name tag in the same color, a two-point highlight around the target window, and a ripple where a click lands. Pointer moves glide over about a quarter second. While the agent thinks between calls, pointer and name tag bounce gently; while a call runs there is no extra motion, since the glides and ripples show the work. The menu-bar list and the Agents pane show the icon of the app each agent works in, with the agent's color as a dot on its corner (just the dot when the app has no icon). The agent cursor switch is in Settings only; the panel is for what is happening now. Each row reads the agent name over "Working in Finder" or "Thinking in Finder"; the token estimate appears only in Settings → Agents.

Menu-bar icon: the app icon reduced to 20 points (sized so the arrow matches neighboring icons' weight): two soft discs with the stemless arrow's tip at their center and a thin gap around the arrow. Idle, it is a template image the system tints. While any agent holds an app (thinking or acting) the discs take that agent's color and a ripple pulses outward every 1.4 seconds; with several agents the pulses alternate between their colors. The arrow then follows the menu bar's text color. The app icon is an Icon Composer document (`assets/icon/`): Airpoint's dark tile and blue ripples with that pointer clicking at their center.
